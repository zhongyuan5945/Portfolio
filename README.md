
  # Designer Portfolio

  This is a code bundle for Designer Portfolio. 

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Run `npm run check` to validate portfolio data, routes, galleries and video loading.
  Run `npm run build` to create the production build.

  See [作品数据维护指南](docs/portfolio-maintenance.md) for adding projects, shops, photo series and videos.
